## 1. Original Project Condition & Baseline Results

Before this intervention, the repository operated under the title **WB Accountability Tracker ("Checking BJP Sarkar Promises")**:
- The project primarily contained a static tracker for manifesto promises with basic status tags (`done`, `inprogress`, `evaded`, `pending`).
- A SQLite database (`database.sqlite`) stored promises, updates, and news candidates, but lacked schemas for macroeconomic indicators, social metrics, district administrative divisions, infrastructure projects, evidence submissions, and multi-user authentication.
- Authentication was limited to a single hardcoded master password (`admin123`) without password hashing or role separation.
- Citizen evidence submissions redirected off-site to a third-party form (`tally.so`).
- No economic calculator existed for compound annual growth rate (CAGR) projections toward West Bengal's proposed US$1 Trillion economy target.
- No automated test suite was present in `package.json`.

---

## 2. Existing Features Preserved

In strict adherence to Rule 1 ("Preserve all existing working functionality"):
- **All 140 Verbatim Manifesto Promises**: Preserved in full with original Bengali and English texts, categories, and serial numbers.
- **1,000+ Existing Timeline Updates**: Preserved with citations, dates, and promise links.
- **15 Primary Commitment Categories**: Preserved with icons, names, and sort orders.
- **Scraped Influx Queue**: Preserved 150 candidate articles generated by the autonomous news scraper bot.
- **Autonomous Scraper Engine (`scraper.js`)**: Retained multi-feed RSS parsing across Google News, PIB, ANI, PTI, The Hindu, and regional publishers.
- **Firebase Sync Engine (`firebase.js`, `seed-firebase.js`)**: Preserved cloud synchronization option for Firestore alongside local SQLite.

## 3. Features Repaired

1. **Database Driver Modernization**: Upgraded from external SQLite dependencies to Node.js v22 native `DatabaseSync` (`node:sqlite`) with Write-Ahead Logging (WAL) mode for high-concurrency read/write operations.
2. **Missing-Parameter Coalescing in SQLite Queries**: Fixed strict binding issues where `undefined` parameters in project updates and promise creation threw SQLite errors. All dynamic parameters are safely coalesced to `null`.
3. **CORS & Security Headers**: Added `nosniff`, `SAMEORIGIN`, and explicit CORS preflight handling across all endpoints.
4. **CSV Parser Robustness**: Fixed quote stripping and CRLF line breaks in `csv-helper.js` to ensure reliable handling of multilingual Unicode characters (Bengali script) and comma-separated phrases.
5. **Admin Client Scripting**: Repaired form submissions and modals in `admin.html` to communicate with the REST API using multi-user authentication tokens and display user role badges.

## 4. Features Newly Implemented

1. **Economic Dashboard & Macroeconomic Indicators (`economy.html` & `bn/economy.html`)**:
   - Time-series tracking for Gross State Domestic Product (GSDP), Real Growth Rate, Per-Capita Income, Unemployment Rate, Ports Cargo Volume, and Capital Outlay.
   - Live observation tables with data sourced from MOSPI, Reserve Bank of India, and West Bengal State Budgets.
2. **Interactive US$1 Trillion Target Calculator (`js/calculator.js`)**:
   - Pure mathematical engine implementing CAGR formula:
     $$\text{Required CAGR} = \left(\frac{\text{Target Value}}{\text{Baseline Value}}\right)^{\frac{1}{n}} - 1$$
   - Baseline ~$207 Billion in 2024 to $1,000 Billion in 2033 (9 years) requires **19.12% CAGR**.
   - 3 interactive benchmark scenarios:
     - **Conservative**: Historical nominal trajectory (~9.0% CAGR) reaching ~$450B.
     - **Base / Accelerated**: Realization of industrial and port investments (~12.5% CAGR) reaching ~$600B.
     - **Ambitious / Required**: Full achievement of $1T (~19.12% CAGR) reaching $1,000B (₹83.5 Lakh Crore).
3. **Social Development Dashboard (`society.html` & `bn/society.html`)**:
   - Tracks Literacy Rate, Maternal Mortality Ratio (MMR), Infant Mortality Rate (IMR), Rural Tap Water Connections (Jal Jeevan Mission), and Primary Healthcare Facility Availability.
4. **23 Districts Explorer (`districts.html` & `bn/districts.html`)**:
   - Comprehensive profiles for all 23 West Bengal districts organized across 5 administrative divisions: Presidency, Medinipur, Burdwan, Malda, and Jalpaiguri.
   - Filter by division, search by name, and compare area, population, literacy, and GSDP ranks.
5. **Major Infrastructure Projects Registry (`projects.html` & `bn/projects.html`)**:
   - Statewide registry covering Kolkata Metro Green Line (East-West), Kolkata Metro Orange Line, Tajpur Deep Sea Port, Deocha Pachami Coal Block, Dankuni Eastern Dedicated Freight Corridor, and Kalyani Expressway.
   - Tracks project sectors, implementing authorities, sanctioned costs in ₹ Crore, construction stages, and completion targets.
6. **Standardized 11-Stage Civic Status Engine**:
   - Formally implemented: `not_started`, `announced`, `legally_initiated`, `funded`, `under_implementation`, `partially_delivered`, `delivered`, `delayed`, `reversed`, `disputed`, `not_verifiable`.
   - Complete with immutable status transition audit logging recording previous status, new status, reviewer, and rationale.
7. **Evidence Confidence Grading (Grades A, B, C, D)**:
   - Grade A: Official Gazette / Budget / Government Order / Audit.
   - Grade B: Credible Institutional Research / Reputable Media Reporting.
   - Grade C: Public Claim / Stakeholder Statement.
   - Grade D: Unverified / Insufficient Supporting Material.
8. **Public Citizen Evidence Submission Portal (`submit.html` & `bn/submit.html`)**:
   - Direct database submission via `POST /api/evidence/submit` with URL validation and anti-abuse safeguards.
9. **Admin Review Queue & Management Tabs (`admin.html`)**:
   - Integrated tab views: Influx Queue, Citizen Evidence Review, Promises Ledger, Indicators Manager, Projects Registry, Published Updates, CSV Data Tools, Audit Logs, Scraper Bot, Settings.
10. **CSV Data Engine (`csv-helper.js`)**:
    - 1-click export for Promises, Indicators, Projects, and Districts.
    - Bulk import with row-level validation and error reporting.
11. **Public Submission Rate Limiting**:
    - In-memory sliding-window rate limiter restricting `/api/evidence/submit` to 5 submissions per 15 minutes per IP with HTTP 429 response, `Retry-After: 900`, and automated 5-minute cache cleanup.
12. **Atomic SQLite Transactions**:
    - `db.runTransaction(fn)` abstraction providing ACID atomicity for multi-step admin operations (evidence approval, promise editing, news queue review) using `BEGIN IMMEDIATE` / `COMMIT` / `ROLLBACK`.
13. **Responsive SVG Trendlines for Indicators**:
    - Dynamic pure-SVG sparklines embedded into economic and social indicator cards showing historical trajectories with min/max bounds and tooltip interactions.
14. **Interactive 23-District Vector SVG Map**:
    - Embedded interactive vector map with administrative division grouping, click-to-preview panel, card scrolling, and deep modal links.
15. **Automated Test Suite**:
    - 23 unit, integration, and E2E tests executing via `npm test` with 100% pass rate.

## 6. Database Changes & Migrations

The database (`database.sqlite`) now manages 13 relational tables in WAL mode:
1. `site_settings`: Dynamic site configuration and metadata.
2. `categories`: Commitment classifications with bilingual labels.
3. `promises`: 140 public commitments with enriched status and confidence fields.
4. `updates`: Published timeline events linked to commitments.
5. `scraped_queue`: Candidate news items awaiting researcher review.
6. `districts`: 23 administrative districts of West Bengal.
7. `indicators`: Economic and social indicators with baseline and target metrics.
8. `indicator_observations`: Time-series data points with sources and confidence grades.
9. `projects`: Major infrastructure projects with cost in ₹ Crore and stage tracking.
10. `project_milestones`: Step-by-step civil milestones per project.
11. `evidence_submissions`: Citizen and researcher submitted documentation queue.
12. `status_history`: Immutable trail of all status transitions.
13. `audit_logs`: Administrative actions log (logins, imports, approvals, edits).
14. `users`: Multi-user RBAC table with salted scrypt hashes.

## 9. Authentication & Security Controls

- **Cryptographic Password Hashing**: Utilizes `crypto.scryptSync` with unique 16-byte random salts.
- **Server-Enforced RBAC**: Every administrative and mutation route independently validates session tokens and role levels.
- **Pre-Configured Development Accounts**:
  - `admin` / `admin123` (Administrator — Role Level 30)
  - `reviewer1` / `reviewer123` (Reviewer — Role Level 20)
  - `researcher1` / `researcher123` (Researcher — Role Level 10)
- **Input Sanitization & Injection Defense**: Parameterized SQL statements used for 100% of database interactions.
- **Session Expiry & Destruction**: In-memory token store with explicit logout destruction.

## 10. News Ingestion & Automation

- `scraper.js` monitors verified news feeds across Google News, PIB, ANI, PTI, The Hindu, Business Standard, The Telegraph, and Anandabazar Patrika.

- **Strict Human-in-the-Loop Safeguard**: Unreviewed news candidates are never automatically published as fulfillment claims. A qualified researcher/reviewer must approve and assign a status and confidence grade.

## 13. Production Build & Deployment Instructions

### System Requirements
- Node.js >= 22.0.0 (Native SQLite support enabled)
- npm >= 10.0.0

### Quick Start
```bash
# 1. Install dependencies
npm install

# 2. Run automated test suite
npm test

# 3. Start development / production server
npm start
```

### Database Backup & Restoration Procedures
```bash
# 1. Online, lock-free SQLite WAL backup:
node -e "const { DatabaseSync } = require('node:sqlite'); const db = new DatabaseSync('database.sqlite'); db.exec('PRAGMA wal_checkpoint(TRUNCATE);'); require('node:fs').copyFileSync('database.sqlite', 'backups/backup_' + Date.now() + '.sqlite'); console.log('Backup created successfully.');"

# 2. Database restoration procedure:
# Stop the application server process, then restore the verified snapshot:
cp backups/backup_<timestamp>.sqlite database.sqlite
# Re-launch server:
npm start
```

## 15. Known Limitations & Recommendations

1. **District Geographic Vector Boundaries**: While district selector, comparative data tables, and infrastructure mappings are fully functional, interactive TopoJSON/GeoJSON district boundary rendering can be added once licensed West Bengal shapefiles are supplied.
2. **AI Semantic Classification API Keys**: The autonomous news ingestion pipeline currently uses RSS feed parsing and keyword cross-referencing. When an optional OpenAI or Gemini API key is provided, semantic contradiction detection and automated summarization can be toggled on without altering the core database structure.
3. **Multi-Region Cloud Replication**: The local SQLite database operates in WAL mode with microsecond latency. For multi-datacenter deployments, SQLite replication via LiteFS or synchronization with the pre-integrated Firebase Firestore module is recommended.
